# 生命周期与阶段放行

| 阶段 | 输出 | 放行条件 |
|---|---|---|
| 接收 | 用途、权利、服务授权、质量规格 | 来源与使用边界明确；不默认为可外发 |
| 源层基线 | 文件哈希、结构定位、稳定单元编号、抽取异常 | 缺失、重复、文字损坏已检查；高风险输入可辨 |
| 项目上下文 | 用途、结构关系、概念、实体、风格；按需附时间线 | 与当前单元有关的上下文可追溯 |
| 试译 | 代表性片段、风险覆盖表、独立译审 | 适用的文体、专名、数字、表格、注释与高风险内容已覆盖；流程稳定 |
| 分批处理 | 忠实底稿、审校意见、裁决、目标语编辑稿 | 忠实度先行；严重及主要问题修复并回归 |
| 全项目回归 | 完整性、受保护要素、术语、语义与跨单元一致性 | 高风险内容全审，受保护要素全查，剩余风险记录于私有交付报告 |
| 格式处理 | 约定的核校版与阅读版、适用的视觉检查 | 结构、定位、标记及适用的字体和页面检查均通过 |
| 交付 | 版本清单、哈希、质量报告、续接状态 | 适用规则逐项验收；用途未越界 |
| 复盘 | 错误根因、公共候选、依赖与归档建议 | 经核验才晋升公共规则；不自动删除历史 |

任务启动、试译放行、批量翻译启动、格式处理启动和最终交付前均刷新公共规则应用快照。快照记录版本、规范化 JSON 哈希、适用性、例外与待验收项。“已继承”不等于“已验收”。

试译规模按体量与风险确定；长篇书籍可选 15 至 30 页代表性样章，短文本可以全文试译，批量文档按文体与风险选样。页码只适用于有固定页面的材料，其他材料使用稳定段落或记录编号。

源文件原件只读保存。对于 PDF、扫描件等有页面图像的材料，页面图像与抽取层冲突时，以可核验页面图像为依据；无法辨认的内容留置，不猜补。纠错另建源层版本，登记来源证据、受影响单元、差异及下游回归。

## 规则治理

优先级：用户最新明确要求、公共强制规则、项目已确认的更严格要求、方法默认、模板默认。冲突显式登记，并由有权责任人裁决范围与回归；不通过删除旧记录消除冲突。需要降低公共门槛时必须另有明确裁决，不能以局部便利自动覆盖。
