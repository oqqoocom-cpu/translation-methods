# 权利、隐私与发布

## 接收时记录

- 文件合法来源、用途、读者、保密级别和传播边界。研究阅读、内部校勘、共享、公开发行和商业使用是不同范围，不能自动升级。
- 外部服务授权：提供方、文本范围、用途、日期与允许的处理方式。默认不发送整本材料。
- 未公开或敏感资料优先本地处理；密钥存于环境或专用密钥系统，不进项目文件。

服务列入评测方案不代表允许上传；扩大范围须另行授权。

## 方法公开，材料私有

公开内容限于通用规则、原创工具、空白结构、纯虚构示例和经核验的外部参考。

不公开真实术语库、实体、页码映射、模型日志、专家记录、译稿与记忆库。即使没有完整正文，它们也可能泄露项目内容。

公开示例从零编写，与实际材料分离。替换作者名、删去少数段落或压缩成图片都不算脱敏。私有来源映射、审计命中、备份及人工批准记录留在私有整理区。

## 发布步骤

1. 按逐文件白名单把通用内容导出到隔离目录。
2. 运行内容扫描、结构验证和工具测试。
3. 在隔离目录初始化独立的本地 Git，不从私有仓库导入历史。
4. 逐类核对许可证范围和署名；代码与文档可以采用不同许可证，但必须逐类说明。
5. 经人工审核并取得明确发布指令后，才提交和推送。

具体操作见 [发布与更新](../PUBLICATION.md) 和 [发布检查表](../RELEASE-CHECKLIST.md)。

## 限制

本库不提供具体法律适用结论，也不保证第三方许可证兼容。引入依赖、模型、字体或数据前分别核验许可与使用条件；已有软件许可不解决书籍素材的权利问题。
