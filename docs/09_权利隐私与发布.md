# 权利、隐私与发布

翻译前记录文件合法来源、用途、读者、保密级别和传播边界。研究阅读、内部校勘、共享、公开发行和商业使用是不同范围，不能自动升级。

外部服务授权须明确提供方、文本范围、用途、日期与允许的处理方式。服务列入评测方案不代表允许上传；默认不发送整本材料。未公开或敏感资料优先本地处理，密钥存于环境或专用密钥系统，不进项目文件。

## 方法公开，材料私有

公开对象限通用规则、原创工具、空白结构、纯虚构样例和经核验的外部参考。真实术语库、实体、页码映射、模型日志、专家记录、译稿与记忆库可能泄露项目内容，即使没有完整正文也不直接发布。

不通过替换作者名、删去少数段落或压缩成图片实现“脱敏”。公开示例从零编写，与实际材料分离。私有来源映射、审计命中、备份及人工批准记录留在私有整理区。

## 发行门槛

逐文件白名单、内容扫描和结构与工具测试通过后，可以在隔离目录初始化独立本地 Git。首次提交与远端发布仍须确认许可证和署名、人工审核及明确发布指令；不从私有仓库导入历史。

本库不内含具体法律适用结论或第三方许可证兼容性保证。引入依赖、模型、字体或数据前分别核验许可与使用条件；已有软件许可不解决书籍素材的权利问题。
