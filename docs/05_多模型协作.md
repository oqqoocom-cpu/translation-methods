# 多模型协作

| 角色 | 输出边界 |
|---|---|
| 主译 | 保留结构、限定与作者立场；疑难留置 |
| 忠实度审校 | 可定位的漏译、误译、逻辑与指代问题 |
| 术语与实体核验 | 冲突、身份及来源候选；不直接改锁定库 |
| 受保护要素检查 | 数字、单位、标记、结构，以及适用的引文、表格和脚注差异 |
| 目标语编辑 | 忠实度通过后的局部差异修改；遵守项目文体 |
| 仲裁 | 依据源文、证据与规则提出裁决建议 |

主译输出译文单元文件；其他角色把意见写成发现，注明 `origin`，`status` 一律为 `candidate`。各角色与程序检查共用 [findings Schema](../schemas/findings.schema.json)，结果可合并去重。

在多个模型或平台之间分配角色时，按相同代表性试译样本的匿名盲测结果分配，不按品牌预设优势；标准级项目可用小规模试译对照代替正式盲测。记录模型标识、版本、参数、提示词、术语条件、日期、成本与采用理由。

需要证明完整流程优于其他路线，或据此选定正式流程时，基准至少比较五条路线：通用平台直接输出、平台加术语表、大模型直接翻译、专业平台初译加模型译后编辑、完整流程。每条路线使用相同样本及评价规则；向外部平台发送试译材料须有单独授权。

审校强度随风险提高：低风险至少用主译加一次独立忠实度审校、确定性检查与抽检；标准级及以上项目按分层角色逐轮审校；高风险内容另需至少两份独立译稿、来源核验和责任人裁决，必要时由相应语种或领域专家复核。多模型共识不替代证据，回译不证明准确。

目标语编辑不能自由重写后直接覆盖。修改以稳定单元编号记录，并再次核对原文。任何优势结论限定语言、文本类型、样本、版本、评价者与日期；未经盲评不宣称全面优于通用平台。

## 多语片段的条件路径

通常优先核对原语言；可靠平行版本用于三角核验，不以连续转译替代原文。抽取损坏时不猜字符，核验裁剪保留完整源语、定位与紧邻平行文本或必要上下文。

仅当同一版面或单元存在明确的中介语平行文本时，允许下述特殊路径；中介语常为英语。非拉丁源语原样保留，固定页面材料按原版影印，不转写、不翻译；目标语只译明示的中介语平行文本。源语保留、中介语文本、目标语转译和原文定位分别留痕，固定页面材料另做页面视觉回归。不得称为源语直译，不能由中介语反推源语、罗马化或逐行对应。没有明确的中介语平行文本，不得用此路径；缺字、对应不清或版面异常仍须留置。
