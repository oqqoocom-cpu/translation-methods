# 排版与交付

双语核校版保留单元编号、原文定位、源文、译文、适用的注释与疑难；目标语阅读版保留定稿、必要译注和低干扰定位。固定页面材料的原页码、引文页码与成品页码分开记录；无页面材料使用稳定单元定位。

B 级以上交付适用的术语、疑难与质量报告。选择研究辅助层的项目另交约定的章节摘要、论点地图、索引与引文定位；一般文档不强制生成研究性附件。输出格式与版式验收按实际用途确定，书籍和印刷规格不套用于所有材料。

## 转换不能改变内容

标题、正文、引文、注释和表格使用可编辑结构及各自样式，不以手工换行模拟段落。生成目录、书签和页码后再核对层级与链接。输出格式按任务规格选择；可编辑文件、PDF 与可重排格式分别检查，不能以一种格式通过推定另一种也通过。

逐页检查孤行、脚注跨页、表格溢出、缺字、混排、右到左文字、影印片段与页码。程序核对内容和结构，独立视觉检查决定版面是否放行。排版意见先形成可定位建议，经裁决再受控写回。

## 内部出版级附加规格

仅适用于明确选择内部出版级的项目：双语底稿、忠实定稿、目标语编辑稿、排版 DOCX、正文印前 PDF、原创封面展开图和纸质校样分层交付。

字体许可明确且允许相应用途与嵌入；封面原创；印前规格包括 3 mm 出血、最终尺寸 300 dpi 图像、字体嵌入、印前预检和纸质样书检查。具体生产参数还须与承印条件核对。标注经确认的内部用途及不对外发行限制；制作精美并不授予发行权。

## 交付核验

交付清单列正式文件的版本、责任人、用途、检查状态与字节哈希。渲染缓存不混入正式成品清单，但需要的视觉证据另行保存和引用。冻结后纠错建立新版本，同步内容、引文、索引、版面、回归及续接说明。
